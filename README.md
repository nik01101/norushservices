# No Rush Services - Web Application

This is a full-stack web application for "No Rush", a company providing professional furniture assembly, mounting, and moving services in New York City. The application allows customers to browse services, get in touch, and book appointments. It also includes a dedicated admin dashboard for managing bookings, messages, and availability.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [ShadCN](https://ui.shadcn.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Backend & Database:** [Firebase](https://firebase.google.com/)
  - **Database:** Cloud Firestore
  - **Authentication:** Firebase Authentication (for admin login)
  - **Deployment:** Firebase App Hosting
- **Address Autocomplete:** [Google Maps Platform](https://developers.google.com/maps)

---

## Features

### Customer-Facing Site

- **Homepage:** An engaging landing page showcasing services, testimonials, and company information.
- **Service Listings:** A detailed view of all services offered, including descriptions and pricing.
- **Online Booking:** A multi-step form for customers to select a service, date, and time, and provide their details.
- **Address Autocomplete:** Integrates with the Google Maps API to provide accurate, validated NYC address suggestions.
- **Contact Form:** Allows users to send direct messages to the business.
- **Gallery:** A showcase of completed projects.
- **Responsive Design:** Fully responsive layout for seamless viewing on desktops, tablets, and mobile devices.
- **Smooth Animations:** Subtle page transitions and fade-in animations for a polished user experience.

### Admin Dashboard (`/admin`)

- **Secure Login:** A dedicated login page for administrators.
- **Booking Management:** View, confirm, cancel, and reschedule upcoming bookings.
- **Availability Control:** Manage available time slots for any given day via an interactive calendar.
- **Inbox:** View and manage incoming messages from the contact form.

## Getting Started

To run this project locally, you will need to have [Node.js](https://nodejs.org/) and `npm` installed.

### 1. Installation

Clone the repository and install the necessary dependencies:

```bash
npm install
```

### 2. Environment Variables

This project requires a Firebase configuration and a Google Maps API key. You will need to set up a `.env.local` file in the root of the project with your Firebase credentials.

Your Firebase configuration can be obtained from your project settings in the Firebase Console.

### 3. Running the Development Server

Once the dependencies are installed and environment variables are set, you can start the development server:

```bash
npm run dev
```

The application will be available at [http://localhost:9002](http://localhost:9002).

## Project Structure

- `src/app/`: Main application routes (App Router).
  - `(public)`: Group for all customer-facing routes.
  - `admin/`: Routes for the admin dashboard.
  - `book/`: Dynamic route for the service booking page.
- `src/components/`: Reusable React components.
  - `ui/`: Components generated by ShadCN.
- `src/lib/`: Utility functions, type definitions, and static data.
- `src/firebase/`: Firebase configuration and initialization.
- `public/`: Static assets like images and fonts.
- `firestore.rules`: Security rules for the Cloud Firestore database.
